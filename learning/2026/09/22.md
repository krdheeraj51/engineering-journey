#### Basic Concept:
- If I am taking about Reflection agent then in simple terms Reflection Agent is design Pattern for desiging an Agent. In this design pattern we focused on designing such type of agents that is capable to self review it's answer and based on that we can get refined version of answers from agent side. So basically when we asked some to LLM then it will give us answer for that question and after that Agent has also capability to recheck that answer and then after it will provide us the final answer.
