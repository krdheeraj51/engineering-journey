# Basic of LangGraph
LangGraph is a framework for building stateful, multi-step, controllable AI applications and agents.

The fundamental idea is:
"Model an AI application as a graph where nodes perform work and edges determine what happens next."

## 🎯 Today's Focus

## 📚 What I Learned

LangGraph is built on top of:

- LangChain (core chains, prompts, models, tools)
- NetworkX (graph structures)

### 1. Core Concept / Architecture

Nodes are like functions that perform a piece of work:
- Can be simple Python functions
- Can be LangChain chains/agents
- Can be LLM calls
- Can be tool calls
- Can be conditional branching logic
